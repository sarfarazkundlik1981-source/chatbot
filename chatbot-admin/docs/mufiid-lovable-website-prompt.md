# Lovable Prompt: Mufiid Responsive Website

Build a polished, SEO-friendly, responsive multi-page website for **Mufiid**, a digital tech education brand that helps aspiring students of knowledge become job-ready in I.T and web development through mentorship, structured lessons, live coaching, practical projects, and career support.

I will upload the Mufiid logo. Use it in the header, footer, favicon, mobile menu, and sign-in/auth screens. The logo style is a purple rounded-square icon with a white "M" and a purple "Mufiid" wordmark. Build the visual identity around a premium dark theme with energetic purple accents.

## Core Brand Direction

Brand name: **Mufiid**

Primary offer: **Zero To Job Ready in I.T**

Audience: aspiring students of knowledge, beginners, career changers, freelancers, agency owners, and people who want flexible online income through practical digital tech skills.

Brand promise: Mufiid helps beginners learn job-ready digital tech skills with mentorship, practice, real-world projects, portfolio guidance, and career support rather than only pre-recorded lessons.

Tone: confident, supportive, professional, modern, practical, and clear. Avoid hype that sounds unrealistic. Use phrases like "in shaaAllah" only where natural and respectful, not excessively.

## Visual Design System

Use a refined dark premium interface inspired by the supplied logo and screenshot.

Colors:
- Background: #08080B or #0B0B10
- Surface panels: #111117
- Elevated cards: #15151D
- Border: rgba(255,255,255,0.08)
- Primary purple: #6D28D9
- Bright purple accent: #8B5CF6
- Hover purple: #7C3AED
- Deep violet: #2D124F
- White text: #F8FAFC
- Muted text: #A1A1AA
- Soft text: #CBD5E1
- Success/accent for stats: #22C55E, used sparingly

Typography:
- Use **Inter**, **Satoshi**, or **Plus Jakarta Sans** for the full website.
- Headings should be bold, tight, modern, and clear.
- Body text should be readable with generous line height.
- Do not use tiny text on mobile.

Layout:
- Desktop max content width: 1180px to 1240px.
- Use consistent vertical spacing: 96px desktop, 64px tablet, 48px mobile.
- Use 8px card radius, 12px only for major containers.
- Buttons should be high contrast and easy to tap on mobile.
- Keep sections full-width with constrained inner content. Do not overuse nested cards.

Hero rule for every page:
- Every page must start with a full-width hero section.
- Every hero section must use a real image or realistic generated image as the background.
- Every hero must have a dark overlay so the light text is readable.
- Hero text must be white or near-white with purple accent words.
- Add subtle background movement or parallax only if performance remains smooth.
- Hero image should be relevant to the page topic, not generic abstract gradients.

Image direction:
- Home hero: diverse students learning web development with laptops in a modern dark workspace, mentor-led online learning atmosphere.
- Program hero: student working through code lessons, project dashboard, and mentor feedback.
- Curriculum hero: close-up of clean code editor, web design wireframes, and learning notes.
- Career Paths hero: professional freelancer or developer working remotely, laptop, portfolio projects.
- Success Stories hero: happy students or graduates in a video-call/community setting.
- Pricing hero: premium online education dashboard or student choosing a plan.
- Contact hero: friendly support/mentor team, laptop, chat/support interface.
- About hero: team mentorship, teaching, collaboration, online classroom.

Use image overlays:
- linear-gradient(rgba(8,8,11,0.78), rgba(8,8,11,0.92))
- Add subtle purple radial glow only as an accent, not the main background.

Animation and interactions:
- Smooth fade-up animations on section entrance.
- Subtle hover lift on cards.
- Purple border glow on active or hovered cards.
- Buttons should have clear hover, focus, and active states.
- Navigation links should underline or glow on hover.
- Pricing cards should highlight the recommended plan.
- FAQ accordion should expand smoothly.
- Forms should show focus states, validation messages, and success states.

Accessibility:
- All text must have strong contrast.
- Buttons must be keyboard accessible.
- Add visible focus rings.
- Images need useful alt text.
- Use semantic HTML.
- Header navigation must work on mobile with a slide-down or drawer menu.

  - FAQ schema for FAQs.
  - Review schema only if real testimonials are supplied.

Important copy rules:
- Do not guarantee employment or income.
- Use careful language: "prepare for", "build toward", "can help", "earning potential varies", "depending on skill, consistency, location, and market."
- Keep the message aspirational but credible.
- Preserve the Islamic phrase "in shaaAllah" only in appropriate brand/story sections, not in every CTA.
